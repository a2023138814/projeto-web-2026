# Projeto de Aplicações Web - Aluguer de Barcos

Trabalho prático desenvolvido no âmbito da unidade curricular de Aplicações Web do Instituto Superior de Contabilidade e Administração de Coimbra (ISCAC).

Composição do Grupo
* Tiago Alves — a2023138814
* Maria Rita Carvalho Simões — 2023138814

Descrição do Projeto
Plataforma web para gestão e reserva de aluguer de barcos. O website permite consultar a frota disponível, visualizar os detalhes e características de cada embarcação e efetuar pedidos de reserva online.

Tecnologias Utilizadas
* HTML5
* CSS3
* JavaScript
* Git & GitHub

Estrutura de Ficheiros
* `index.html` - Página principal do website
* `css/` - Ficheiros de estilos visuais
* `js/` - Scripts de interatividade
* `images/` - Recursos visuais e imagens dos barcos
